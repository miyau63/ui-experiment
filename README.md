# Результаты обработки пилотного эксперимента с отслеживанием взгляда при генерации эллипсиса

В этом репозитории представлены результаты обработки данных пилотного эксперимента по отслеживанию движений глаз (**eye-tracking**).

## Содержимое репозитория

```text
.
├── overlay_heatmap/     # Изображения с тепловыми картами
├── analysis_results/    # Файлы с вычисленными метриками движений глаз
├── data/                # Полученные в результате эксперимента данные движения глаз
└── README.md
```

Представленные результаты получены в рамках **пилотного эксперимента**. Они носят предварительный характер и не должны рассматриваться как окончательные выводы исследования. Перед интерпретацией результатов рекомендуется проверить качество записи, полноту данных и критерии фильтрации.
